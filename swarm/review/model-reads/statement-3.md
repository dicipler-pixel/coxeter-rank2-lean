# Audit report — statement 3, `affine_unipotent`

Auditor: member m1. Scope: statement 3 only. I did not modify the repository (see last section).

Statement as frozen in `swarm/Statements.lean` (T3), with its docstring:

```lean
/-- Every rank-two representative with `a*b = 4` is unipotent: `(T - 1)² = 0`. -/
theorem affine_unipotent (a b : ℕ) (ha : 1 ≤ a) (hb : 1 ≤ b) (hab : a * b = 4) (v : V) :
    step (a : ℤ) (b : ℤ) (step (a : ℤ) (b : ℤ) v) = 2 • step (a : ℤ) (b : ℤ) v - v
```

`V = ℤ × ℤ`, `step a b = s1 a ∘ s2 b`, `s1 a (x,y) = (-x + a y, y)`, `s2 b (x,y) = (x, b x - y)`.
In matrix terms `step a b` acts by `T = [[a b - 1, -a], [b, -1]]`, so the conclusion is
`(T² - 2T + 1) v = 0` for all `v`, i.e. the operator identity `(T - 1)² = 0`.

## True, but what it does and does not say

The proposition is exactly its docstring: a genuine operator identity, quantified over all `v : V`
with no witness and no implication-conjunction, so the brief's quantifier concern does not bite
here — it is uniform in `(a,b)` over a set with three elements, `(1,4), (2,2), (4,1)`, which is
exactly Kac's full rank-two affine list (not the single worked example `(2,2)`), and that is also
what the module header claims ("for all three representatives"). It is **not vacuous**:
`step 2 2 (1,0) = (3,2)`, `step 1 4 (1,0) = (3,4)`, `step 4 1 (1,0) = (3,1)`, all `≠ (1,0)`.

Three things a reader should not over-read into it.

1. **It is the unipotence half only.** `(T-1)² = 0` alone is satisfied by `T = 1`; the affine
   conclusion proper is `T = I + N` with `0 ≠ N`, `N² = 0`, hence `Tⁿ ≠ 1` for every `n ≥ 1`
   (linear drift). That is not in this statement; it is in `affine_iterate` and
   `affine_no_positive_period`, and the README attributes drift and "no positive period" to the
   trio, not to `affine_unipotent` alone. So the name/docstring promise nothing extra, but
   statement 3 by itself settles neither the infinity of the group nor the classification.
2. **The hypotheses are stronger than the conclusion needs, and exactly right as a
   characterisation.** Over `ℕ`, `a*b = 4` forces `a,b ≥ 1`, so `ha`/`hb` are derivable
   (`AuditS3.lean` proves both); and the operator identity holds for every `a,b : ℤ` with
   coefficient `ab - 2` (Cayley–Hamilton), so `ab = 4` is used only to set that coefficient to `2`.
   In the other direction nothing is missing: for `a,b ≥ 1` both proper principal minors of
   `cartan a b` are `2 > 0` and `det = 4 - ab`, so Kac's criterion gives "affine ⟺ `a b = 4`" —
   the hypotheses cut out precisely the affine rank-two GCMs, in the regime where `cartan a b` is
   a GCM at all (`a_ij ≤ 0` for `i ≠ j`, symmetrisable by `diag(b,a)`; with `a` or `b` negative
   the off-diagonal would be positive and `cartan` would not be a GCM).
3. **"Unipotent" is not an artefact of the two-dimensional linear model.** For all three pairs
   `T = I + N` with `N ≠ 0`, `N² = 0`, so `T` has infinite order; consequently the group
   generated by the two involutions `s1`, `s2` (both are involutions, `RankTwoCertificate.s1_involution`,
   `s2_involution`) is infinite dihedral `= I₂(∞)`, the Coxeter group of the Coxeter matrix with
   `m = ∞`. So the representation *is* faithful in this rank-two affine case, and the statement is
   about the affine Coxeter group itself. (One convention note: the repo's `s1 a`, `s2 b` are the
   two simple reflections `s_i λ = λ - ⟨λ, α_i^∨⟩ α_i` of the geometric representation for the
   matrix `cartan b a`, i.e. with the two off-diagonals interchanged; both orders `(1,4)` and
   `(4,1)` occur among the three pairs and the conclusion is symmetric in `a b`, so nothing is
   lost. Note also that the 2×2 `step` is the Coxeter *transformation of the geometric
   representation*, where the affine translation appears as unipotence — it is not the
   affine-plane reflection group, whose Coxeter element is a translation with identity linear part.)

Depth: the mathematical content is one line of Cayley–Hamilton. The statement's value is coverage
— all three rank-two affine GCMs at once, uniformly in `(a,b)`, which is what `LIMITATIONS.md`
claims ("the affine statements at `a*b = 4` are general in `(a, b)` … from the characteristic
polynomial identity `step² = (a*b - 2) • step - 1`"). I verified that claimed identity; it is
correct as stated.

- That the affine Coxeter element is a *translation* in the affine Weyl group (`W_a = L ⋊ W₀`) —

  reflections in parallel mirrors compose to a translation) and needs no citation.

My own derivation, which needs no literature: for `a,b ≥ 1`, `det cartan a b = 4 - ab` and the
proper principal minors are `2`, so Kac's criterion gives "affine ⟺ `ab = 4`"; and
`char poly(step a b) = λ² - (ab-2)λ + 1`, which at `ab = 4` is `(λ-1)²`, whence `(T-1)² = 0` by
Cayley–Hamilton. The same computation shows the trichotomy for `a,b ≥ 1` (all verified by
`audit-computation.py`): `ab ≤ 3` ⟹ finite order `2, 3, 4, 6`; `ab = 4` ⟹ nontrivial unipotent,
infinite order; `ab ≥ 5` ⟹ real eigenvalues `≠ ±1`, infinite order.
